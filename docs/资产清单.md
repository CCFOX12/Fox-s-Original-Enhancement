# 资产清单

2026-09-28。对照当前 Fabric 工程里已经注册的物品。原版剑、斧、镐、铲、锄、矛、三叉戟、重锤、弓、弩、盾只改了数值，继续用原版模型和贴图。

现在全部自制物品共用 `vplus:placeholder`（紫黑未知图标）。资源目录里没有物品 png，也没有穿戴模型。

画好的文件先放在本目录 `assets/` 下，文件名与下表 id 一致。

| 用途 | 放到 |
| --- | --- |
| 物品贴图 | `assets/textures/item/<id>.png` |
| 盾的格挡模型 | `assets/models/shield/<轮廓>.json`，贴图仍按物品 id |
| 穿戴模型 | `assets/models/worn/<id>.json` |

规格：16×16，原版像素，透明背景。同一种武器或盾只换材质颜色，轮廓相同。木头的 id 前缀是 `wooden`，金是 `golden`。

## 数量

| 类别 | 物品贴图 | 模型 |
| --- | --- | --- |
| 自制武器 | 81 | 手持可先用贴图平面。要立体手持时，11 种轮廓各 1 个模型，材质只换贴图 |
| 自制盾 | 含在上面 81 里（27 张） | 4 种轮廓各 1 个格挡模型 |
| 装备、袋子、食物、附魔锭 | 12 | 不需要。肩甲若要露在身上，另加 1 个穿戴模型 |
| 技巧模板、钻孔模 | 10 | 不需要 |
| 装扮与矿工头灯帽 | 130 | 116 个穿戴模型。14 张样布只是物品，不穿 |
| 合计 | 233 张贴图 | 4 个盾模型 + 116 个穿戴模型。立体武器手持另计 11 个 |

附魔铜锭、附魔铁锭、附魔金锭、附魔下界合金锭可以沿用对应原版锭的贴图，只靠附魔闪光区分。若要在物品栏里一眼分开，再各画一张。

挂带、腋下和背上不另做模型，复用那把武器、那面盾或那只灯笼自己的物品模型。
