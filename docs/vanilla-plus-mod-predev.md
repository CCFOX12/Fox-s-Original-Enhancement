# 原版增强模组 · 预开发内容清单

状态：预开发 / 可持续追加  
最后更新：2026-09-28  
原版基线：Java 1.21.11（Mounts of Mayhem）。矛、铜工具、干骸按已实装内容写入。废弃营地要到 26.3 才有，本期不做。冰洞僵尸与第四维度 The Sift 尚未实装，本期不预做。

设计备忘：

- 装扮以战利品与交易获取为主，不做成工作台量产时装柜
- 展示装扮只改外观。怪物装扮另外缩短对应怪物的跟随距离。功能装扮有效果，但不是护甲；外观可以单独关掉，效果仍在
- 武器（含原版）统一走类 D&D 规则：类别、伤害类型、武器属性、固定数值；不掷骰
- 额外格子画在原版物品栏右侧，本模组自己做界面。不依赖 Accessories，也不做成独立 RPG 套装系统
- 加载器：Fabric 与 NeoForge 都做，一份共用代码。按键、事件、网络包按加载器各写一薄层。不用旧版 Forge，不用 Quilt，也不靠兼容层把 Fabric 包跑在 NeoForge 上
- 不新建元素伤害表，不新开维度，不完整变身
- 武器词条分两路：锻纹、镶嵌；两者都类似附魔，但走高炉 / 锻造台，不走附魔台
- 技巧模板是本模组附魔：一把一条，带一个主动或触发式特效。锻造台当模板消耗，工作台按锻造模板的方式复制，不进附魔台

## 1. 装扮类

装扮分成两套，画在原版物品栏右侧的一列里，和肩甲、锁链内衬、三条挂带放在一起。不占头盔、胸甲、护腿、靴子。不使用 Accessories。

### 1.0 两套装扮槽

同一部位可以同时穿一件展示和一件功能。展示件 ID 前缀 `cosmetic/`，功能件前缀 `utility/`。两边的物品不能互换格子。

| 套   | 槽   | 槽标识                  | 穿着之后     |
| --- | --- | -------------------- | -------- |
| 展示  | 头饰  | `vplus:display_head` | 只换模型     |
| 展示  | 外套  | `vplus:display_coat` | 只换模型     |
| 展示  | 裤装  | `vplus:display_legs` | 只换模型     |
| 展示  | 鞋履  | `vplus:display_feet` | 只换模型     |
| 功能  | 头   | `vplus:utility_head` | 有效果，外观可关 |
| 功能  | 衣   | `vplus:utility_coat` | 有效果，外观可关 |
| 功能  | 腿   | `vplus:utility_legs` | 有效果，外观可关 |
| 功能  | 鞋   | `vplus:utility_feet` | 有效果，外观可关 |

第 3 节的内衬、肩饰和三条挂带也在这一列里，见 3.0。那些是携带和防护配件，不进这两套装扮。挂带解锁的延伸格紧挨着对应挂带。

**展示套**

结构装扮和职业衣只渲染模型，不提供光照、属性或仇恨变化。怪物装扮同样不把玩家伪装成那种生物，但会缩短对应怪物的跟随距离，见 1.1。矿工头灯帽不在展示槽，它是功能头槽的物品。

| 槽   | 典型内容       | 与盔甲               |
| --- | ---------- | ----------------- |
| 头饰  | 帽、角、头纱、面具  | 戴着头盔时隐藏模型，卸下头盔后恢复 |
| 外套  | 袍、斗篷、整件外观、围裙 | 鞘翅飞行时隐藏模型，落地后恢复   |
| 裤装  | 腿部布料       | 与护腿同时显示，护腿在外      |
| 鞋履  | 靴、裹足       | 与靴子同时显示，靴子在外      |

**功能套**

不是护甲：无护甲值、无韧性，穿上也不算「有甲」。效果在物品放进功能槽时就生效。

每一格有自己的「显示外观」开关，默认开。关掉之后不渲染这件的模型，效果保持。头盔挡住功能头的模型、鞘翅飞行挡住功能衣的模型时，同样只藏模型，不关效果。

头灯这期只做废弃矿井的 **矿工头灯帽**，放功能头槽。箱子概率仍是 15%。亮度和灯笼相同。关掉外观后模型不画，光还在。展示头槽不继承这顶帽子的光。

**显示与掉落**

- 同一装饰槽后穿的替换先穿的，被替换的那件回到物品栏。
- 皮革染色、盔甲纹饰不改变装扮。除牧羊人衣外，装扮颜色做死在物品上。
- 死亡时按原版盔甲规则掉在地上。
- 展示装扮无耐久、无护甲值、无韧性、无套装加成。功能装扮也无护甲值和韧性。
- 怪物装扮不降低仇恨，也不会让同种生物把玩家当成自己人。它只缩短那种怪物的跟随距离。

**不掉装扮的对象**

村民、僵尸村民、流浪商人、铁傀儡、雪傀儡、铜傀儡、悦灵、蜜蜂、鹦鹉螺、各种被驯服的坐骑。这些要么走交易，要么是生产型生物。僵尸马、骆驼尸壳、僵尸鹦鹉螺仍会掉，它们在被驯服前按敌对生物处理。

### 1.1 怪物装扮

来源：玩家击杀，或玩家驯服的狼击杀。环境伤害、熔岩、掉落致死不算。每只怪最多额外掉 1 件，不替换它原有的掉落。

抢夺每级 +2 个百分点，加到该组上限为止。抢夺不影响「掉哪一件」，只影响「掉不掉」。

| 变体  | 10%             | 24%  | 干骸、洞穴蜘蛛、唤魔者、劫掠兽、恼鬼、猪灵蛮兵、守卫者、远古守卫者、旋风人、嘎枝、疣猪兽、僵尸疣猪兽、末影人、烈焰人、恶魂、岩浆怪、史莱姆、潜影贝、幻翼、蠹虫、末影螨、僵尸马、骆驼尸壳、僵尸鹦鹉螺 |

**部位**

人形：头饰 30 / 外套 40 / 裤装 20 / 鞋履 10。  
无四肢或身体连成一块的：只掉 1 件「整件外观」，占外套槽。  
末影人、监守者：头饰与外套两件，各 50%。  
末影龙：只掉龙角头饰（头饰）。凋灵：只掉外套。

命名色：怪物装扮白色。同一种怪的四件可以混穿，没有凑齐奖励。

**跟随距离**

只影响这件装扮对应的那一种怪物。看见了照样攻击。其它生物不变。改的是跟随距离：更晚进入追击，已经在追也会更早跟丢。

身上该种怪物的装扮有几件，跟随距离就乘几次 0.85。四件大约是原来的一半（0.85^4 ≈ 0.52）。不同怪物的件数分开算。

整件外观在件数上按 4 件算，所以一件就大约减半。末影人、监守者是头饰加外套，最多两件，大约是原来的 72%（0.85^2）。末影龙的龙角头饰、凋灵的外套各只算 1 件，乘一次 0.85。

格子里有这件就算件数。头盔挡住模型，或功能槽关掉外观，都不把这件从件数里拿掉。

### 1.3 村民职业衣物

覆盖全部 13 个有工作方块的职业。必须是这个职业、并且已经解锁对应等级的村民本人出售。失业村民、婴儿、流浪商人不卖衣。

衣服不能在织布机上凭空挑选。村民卖的是「样布」，样布再进织布机。

**织布机**

3. 2 秒后弹出 1 件衣物，消耗样布和羊毛。
4. 一次一件。织布机不提供职业列表，没有样布就织不出衣服。

样布堆叠 16，不能穿。基础价会吃原版村民的涨价和折扣。

### 1.4 滑稽装扮

傻瓜村民给出的装扮统称 **滑稽装扮**：各种有趣的外观，和职业衣分开。没有职业等级，不能把样布放上织布机，也不进 1.3 的表。换装扮不用绿宝石界面，流程与猪灵用金锭以物易物相同。这些都是展示装扮，进展示槽。

**美味面包**

熔炉上格放面包，燃料任意，烧炼时间与烤肉相同（200 tick）。烟熏炉和营火不产这件物品。产出堆叠 64。

玩家吃下去时，饥饿恢复与面包相同，为 5 点。饱和度在面包的 6 点上再加 1，为 7。

**和傻瓜村民交换**

只接受成年傻瓜村民。婴儿、失业村民和任何有职业的村民都不捡美味面包。

1. 玩家把美味面包扔在傻瓜村民附近。
2. 傻瓜村民走过去捡起 1 个，举到眼前端详 6 秒。这 6 秒内不再捡下一个。
3. 端详结束，朝玩家扔出 1 件滑稽装扮，消耗这 1 个美味面包。
4. 一次一个面包，换一件。地上还有面包时，可以接着捡。

端详途中这个傻瓜村民受到伤害，或开始变成僵尸村民，美味面包掉在脚下，这次不扔装扮。装扮本身仍是纯外观，命名色金色。

清单没有条目时，傻瓜村民不捡美味面包。美味面包仍可食用。

## 2. 武器类（固定伤害，不掷骰）

本节同时覆盖 **原版武器** 与 **本模组武器**。原版数值按同一套规则重标定，不再沿用 Mojang 的铁斧 9 伤 / 0.9 速等独立表。

不使用骰子。D&D 里的 `1d4 / 1d6 / 1d8 / 1d10 / 1d12 / 2d6` 全部改成固定伤害阶。

### 2.1 核心定义

**类别**


| 类别  | 含义                                           |
| --- | -------------------------------------------- |

### 2.8 伤害结算顺序

一次命中按这个顺序算。空手跳过第 4 步。

1. 取表内伤害，并已经按材质升阶或减伤。
2. 加上固定加值：锻纹的 +N、镶嵌物的 +N、原版附魔的固定加值（锋利、亡灵杀手、节肢杀手、穿刺）。
3. 条件加值在这一步加上，例如对残血、对举盾、背后、满血第一击。
4. 乘伤害类型修正。有甲 = 目标护甲值 > 0。只有内衬、只有盾、护甲值为 0，都算无甲。
5. 乘锻纹里写明的百分比（甲击、重甲击那一类）。
6. 暴击。基础倍率 1.5。长刀「重暴击」是 +0.25，紫水晶镶嵌物是 +0.25，加法，不连乘。两样都在则为 2.0。
7. 横扫、震击、追加是另一次结算，用本击结果乘它们自己的比例，不再暴击，也不再触发追加。
8. 防御方最后结算：盾的减免、保护附魔、内衬的 −1。

锋利沿用原版数字：等级 ×0.5，再加 0.5。即 I = 1，II = 1.5，III = 2，IV = 2.5，V = 3。亡灵杀手、节肢杀手、穿刺也沿用原版每级加值，并且不改变挥砍 / 穿刺 / 钝击。

盾的减免：最终伤害 ×（1 − 防护加值 × 0.15），并且免疫这次击退。内衬在这之后再减 1，最低剩 1（本次原始伤害至少为 2 才减）。

例：铁剑 6，锋利 III，锻纹锋刃 +1，挥砍，打有甲目标。  
6 + 2 + 1 = 9，挥砍对甲 ×1 = 9。对方中盾 +2，9 × 0.70 = 6.3。若对方还有内衬，变为 5.3。

### 2.10 重量与移速

重量只影响地面行走。游泳、鞘翅、坐骑速度不吃重量。

```
超出 = max(0, 主手重量 + 副手重量 − 6)
移速倍率 = 1 − min(0.15, 超出 × 0.01)
```

再依次乘：拿在手上时的重型 ×0.90、当前盾的举盾移速。挂在腰带、肩带、背带上的武器不计重量，也不吃重型减速。


| 例子              | 计算                        | 行走倍率   |
| --------------- | ------------------------- | ------ |
| 细剑 2 + 中盾 6，未举盾 | 超出 2                      | ×0.98  |
| 同上，举盾           | ×0.98 × 0.80              | ×0.784 |
| 大铁锤 10，副手空      | ×0.96 × 重型 0.90           | ×0.864 |
| 重盾 16，举盾      | ×0.90 × 重型 0.90 × 举盾 0.45 | ×0.365 |


### 2.11 横扫、双持、投掷、破盾

**横扫**

每把武器只用自己的横扫比例。剑 40%，砍刀 50%，锄的锻纹「小横扫」是 30%。这些比例不互相叠加。副手攻击不产生横扫。默认额外打中 3 个目标；锻纹「多横扫」改为 4 个。扇形范围用原版横扫。

**双持**

副手只能是另一把轻型进攻武器。一次点击同时结算两下，不是两套独立攻速。

- 主手按表内伤害，副手 ×0.50。
- 双持时攻速锁为 1.40。单持短剑仍是 2.20。
- 距离取较短的一把。
- 副手那一下用副手的伤害类型，不横扫，不破盾。
- 锻纹和镶嵌物只结算在自己那只手上。

铁短剑双持，对有甲：主手 5 与副手 2.5 都吃穿刺 +20%，再乘 1.40，约 12.6 / 秒。铁剑单手对有甲约 9.6 / 秒。多出来的部分用掉盾和 2.6 的距离支付。对无甲时双短剑约 9.5 / 秒，与剑的 9.6 接近。

**举盾与快武器**

举盾期间，主手失去轻型、灵巧带来的攻速。细剑从 1.80 回到 1.60，短剑从 2.20 回到 1.60。盾只是拿在手上、没有举起时，不触发这条。

铁细剑举盾后对有甲约 11.5 / 秒，并吃中盾 30% 减免。不举盾时仍是 1.80，用盾的减伤换这一档攻速。

**盾击**

举盾时按攻击键是盾击，不是主手攻击。冷却 0.8 秒，不吃攻速词条。伤害用盾表，类型为钝击。重盾的盾击伤为 0，举盾时攻击键无效。技巧模板「冲撞」不替换盾击，它走点按使用键，见 2B。

**投掷**

- 近程内伤害 = 该武器当前持握伤害。远程内 ×0.75。超出远程无伤害。
- 有忠诚：命中或落地后飞回，不留在地上。
- 无忠诚：飞斧落地成物品；竹镖、矛、三叉戟可插地捡回；飞刀不回收。
- 飞刀一次消耗 1 把。堆叠飞刀的规则见 2A.4。

**破盾**

实际禁用秒数 = 武器特记与盾表「破盾禁用」里较大的那个。锻纹「拆盾」的 +2 秒加在这个结果上。斧的「延长破盾」先把斧的 5 秒改成 6.5，再去和盾表取较大值。

斧打小圆盾 = max(5, 3) = 5。大铁锤打重盾 = max(5, 10) = 10。

### 2.12 矛的戳刺与冲锋

戳刺走 V08。无横扫。单手 5 / 双手 6，双手攻速 1.20，距离 4.0。

投掷是本模组按「投掷」属性加上的。近 8、远 16。冲锋过程中不能投。

冲锋按住副交互：


| 阶段  | 时间     | 效果                    |
| --- | ------ | --------------------- |
| 预备  | 0.35 秒 | 尚不能造成冲锋伤害             |
| 咬合  | 1.2 秒  | 有击退。相对速度 ≥ 6 格/秒时打下坐骑 |
| 力竭  | 0.8 秒  | 有击退，不能打下坐骑            |
| 脱力  | 松开前    | 无击退，本次伤害减半            |


松开后 1.5 秒才能再次冲锋。

相对速度 = 攻击者速度在朝向上的投影，减去目标速度在同一朝向上的投影。迎面来的目标算更快，同向逃跑的目标算更慢。

相对速度 ≥ 4.6 格/秒时，额外伤害 = min(上限, floor(相对速度 × 0.5))。低于这个速度没有额外伤害。额外伤害与戳刺相加后，再走穿刺修正。


| 材质    | 额外伤害上限 |
| ----- | ------ |
| 木、石、铜 | +3     |
| 铁、金   | +4     |
| 钻石    | +5     |
| 下界合金  | +6     |


疾跑约 5.6 格/秒时，铁矛额外 +2，戳刺 5 合计 7，对有甲约 8.4，仍低于大铁锤的站桩伤害。更快的坐骑会被上限卡住。

猛冲附魔只加咬合阶段的移速：每级 +8%（I–III）。不提高额外伤害上限。冲锋命中额外扣 1 点耐久。

## 2B. 技巧模板

技巧模板是本模组自己的附魔。名字取短词，一条就是一个动作或一个触发，强度停在「能改变这一下怎么打」，不到锻纹彩虹那种程度。

和另外三路词条的分工：


|      | 原版附魔   | 锻纹        | 镶嵌     | 技巧模板        |
| ---- | ------ | --------- | ------ | --------- |
| 典型效果 | 锋利、耐久  | 一条属性或情境加值 | 镶嵌物固定值  | 一次撞击、一阵爆风 |
| 数量   | 按原版冲突组 | 1 条       | 最多 2 槽 | 1 条       |
| 获得   | 附魔台、铁砧 | 出厂或高炉     | 锻造台    | 锻造台消耗技巧模板   |


一把物品可以同时有锻纹、镶嵌、原版附魔和一条技巧模板。技巧模板之间互斥。技巧模板不占附魔条目，附魔已满时仍能装上。它没有 I–V 级。

物品是单独的「技巧模板：××」，行为与锻造模板相同：不是附魔书，不能放进附魔台，也不能在砂轮上刮回来。堆叠 64。

**装上**

锻造台：

- 模板槽：技巧模板
- 基底：合适的武器或盾
- 材料槽：空着

技巧模板被消耗。类型不合的技巧模板放不上去。已经有技巧模板时，再放一枚新的盖掉旧效果，旧技巧模板不返还。不消耗经验。钻孔模具和技巧模板不能混用。

**复制**

配方与下界合金升级模板相同。工作台：

```
钻石 技巧模板 钻石
钻石 钻石 钻石
钻石 钻石 钻石
```

产出 2 枚同一枚技巧模板。先复制再拿去锻造，用掉的那枚不会从砂轮里退回来。

砂轮把技巧模板和原版附魔一起清掉。铁砧合并两把同武器时技巧模板留左边。修耐久不动技巧模板。

结算以服务端为准。挂在腰带、肩带、背带上时不生效。

**战斗冷却**

在战斗里发动或触发的技巧模板都有冷却。冷却从这一下打出去或被打中触发时开始，记在玩家身上。换手、放进挂带、换一把带同一条技巧模板的武器，都不刷新。冷却中不能再次发动；爆风在冷却中即使格挡成功也不再爆风。物品栏里的技巧模板图标按原版食物那样转冷却。

冲撞结束后的 0.20 秒不能攻击，那是出手硬直，不代替下表的冷却。爆风另有一条目标间隔：同一目标 1.5 秒内只被弹一次，和使用者的 3 秒冷却分开算。


| 技巧模板  | 冷却                                | 起算     |
| --- | --------------------------------- | ------ |
| 冲撞  | 小圆盾 1.2 秒；中盾、原版盾 1.6 秒；大盾 2.2 秒；重盾 2.8 秒 | 开始短冲   |
| 爆风  | 3 秒                               | 格挡爆风   |
| 扇形斩  | 3.0 秒                             | 点按挥出   |
| 突刺  | 2.5 秒                             | 点按冲出   |
| 跺地  | 3.5 秒                             | 点按顿地   |

**点按和长按**

使用键按住超过 0.18 秒是长按，短于这个时间松开是点按。

- 盾：点按发动盾上的主动技巧模板，长按仍是举盾。冷却中点按没有动作，长按照常举盾。
- 主手是弓、弩、矛、三叉戟时，使用键先给主手。这时盾的主动技巧模板改成潜行后再点按，避免吃掉拉弓和冲锋。
- 剑、斧、锤这类没有长按功能的武器：点按使用键发动主手技巧模板。
- 弓、弩、矛、三叉戟、飞斧、飞刀、竹镖本期不装技巧模板。它们的使用键留给射击、冲锋和投掷。

破盾禁用期间，盾上的技巧模板不能发动，也不触发。

### 2B.1 冲撞（A01）

适用：全部盾，含原版盾。

点按使用键，盾面向面朝方向短冲，撞上路径上第一个生物后停下。撞到方块也停下。这一下是钝击，走 2.8 的类型修正和对方的盾减免，不暴击，不吃锻纹「强盾击」。不破盾。冲刺中断疾跑，不计算为摔落起跳。结束后 0.20 秒内不能攻击，这段时间可以长按举盾。

### 2B.2 爆风（A02）

适用：全部盾，含原版盾。

成功格挡的同一下触发。格挡角以外的攻击、背后、破盾已经开始之后的攻击，都不触发。

表现顺序：

1. 盾面出现一枚原版风弹的模型。
2. 2 tick 后它在原地爆炸，播放风弹命中的粒子和音效。
3. 爆炸这一拍对范围内的敌人结算击退和伤害。

这枚风弹只用来看。它不飞行，不推动方块，也不改动方块状态。


| 盾      | 半径    | 水平击退 | 垂直速度 | 伤害  | 冷却  |
| ------ | ----- | ---- | ---- | --- | --- |
| 小圆盾    | 1.8 格 | 0.7  | 0.25 | 2   | 3 秒 |
| 中盾、原版盾 | 2.2 格 | 0.9  | 0.30 | 2   | 3 秒 |
| 大盾     | 2.6 格 | 1.1  | 0.35 | 2   | 3 秒 |
| 重盾   | 3.0 格 | 1.3  | 0.40 | 2   | 3 秒 |


伤害是钝击，走类型修正，不暴击，不触发主手或盾上的锻纹。垂直速度只把人弹离地面一小段，不是升空。

每次触发消耗盾 1 点耐久。同一目标 1.5 秒内只被爆风弹一次。

弹飞敌对生物，以及已经被激怒的中立生物。不弹村民、已驯服生物、玩家自己的坐骑。其它玩家只在该次伤害允许对玩家生效时弹飞。

和相邻词条的关系：锻纹「反击」仍只打中正在打你的那一个，爆风另算范围内的人。锻纹「弹回」照常尝试弹回弹射物。格挡减免先算，然后才是爆风。斧头这一下如果打破了盾，爆风仍然对这一下生效，随后盾进入禁用。

## 2A. 锻纹与镶嵌

游戏内名称：**锻纹**、**镶嵌**。  
两者都是武器上的词条，展示方式类似附魔（物品光效、tooltip 分节），但不占用原版附魔台流程。


|       | 锻纹             | 镶嵌                     |
| ----- | -------------- | ---------------------- |
| 获得    | 出厂随机，或高炉重铸     | 锻造台开槽后镶嵌               |
| 数量    | 同时只保留 **1 条**  | 每把武器 **1 个槽**（模具可升到 2） |
| 洗掉    | 砂轮             | 砂轮只卸镶嵌物，不关槽            |
| 和工作站  | 高炉 + 铸造金属      | 锻造台 + 钻孔模具 + 金属/宝石     |
| 和原版附魔 | 互不覆盖；锻纹不计入附魔条数 | 镶嵌可增加「附魔条目」上限          |


原版武器、本模组武器都可锻纹、都可钻孔。盾可锻纹，但镶嵌模具单独一类。

---

### 2A.1 锻纹

**出厂**

- 合成、战利品、村民卖出的武器，生成时在 **低阶锻纹池** 抽 1 条。
- 空手、箭、原版未当作武器的物品不会带上锻纹。
- 出厂词条在物品描述里标为「锻纹 · 普通 · ××」，名称白色。

**砂轮**

- 对有锻纹的武器用砂轮：去掉锻纹，得到 **空白武器**。
- 不返还经验，不毁掉原版附魔。
- 空白武器可重新附魔、可进高炉、可钻孔。

**高炉重铸**

配方（高炉，烧炼时间同金锭）：

- 上：空白武器。带锻纹「保底」的武器是例外，可以直接放入
- 下：1× **附魔锭**，或 1× 铜块 / 铁块 / 金块
- 燃料：任意

产出：同一把武器 + 一条新的锻纹。耐久、原版附魔、已开槽、已镶嵌物全部保留。

**铸造金属**

任何金属都能铸，但上限和权重不同。锭与块都能用，块按 9 锭计算权重（更容易出高阶，不额外多给词条条数）。


| 铸造金属         | 基础权重（低/中/高/彩虹）         | 备注     |
| ------------ | ---------------------- | ------ |
| 铜锭           | 72 / 24 / 4 / 0        | 不出彩虹   |
| 铁锭           | 56 / 30 / 13 / 1       | 默认     |
| 金锭           | 40 / 32 / 22 / 6       | 波动大    |
| 下界合金锭        | 12 / 26 / 42 / 20      | 彩虹主要来源 |
| 铜块 / 铁块 / 金块 | 同对应锭，高、彩虹权重 ×1.5 后再归一化 | 耗材更贵   |


能带附魔进高炉的是新物品 **附魔锭**，不改原版锭。高炉：上格金属锭，下格紫水晶碎片，时间同金锭，产出对应附魔锭（铜 / 铁 / 金 / 下界合金）。附魔锭可上附魔台，未附魔时可堆叠 64，附魔后按原版规则不可堆叠。权重与同金属锭相同。

金属块不能附魔，附魔点数视为 0，只享受表里的 ×1.5。下界合金块不参与铸造。原版锭放不进这台高炉的下格。

**附魔如何改权重**

先算金属的 **附魔点数**：

```
附魔点数 = 所有附魔等级之和 + 不同附魔种类数 × 2
```

例：锋利 III + 耐久 II → 附魔点数 = 3 + 2 + 2×2 = 9。

然后把基础权重里的「高、彩虹」按附魔点数上推：

```
高阶权重 += 附魔点数 × 2
彩虹权重 += max(0, 附魔点数 − 6) × 2
低阶权重 -= 附魔点数 × 2
```

权重最低削到 0，再归一化成概率。  
未附魔铁锭几乎总是白 / 金。金锭堆满附魔才较常见蓝。下界合金 + 高附魔点数才稳定刷彩虹。

铸造消耗金属（含其上附魔）。失败不存在，总会写出 1 条锻纹。

**品阶、颜色、光效**

品阶决定 **进哪一个词条池**，不是同一条词条乘倍率。低阶池全是小数，彩虹池全是独特效果。


| 品阶  | 颜色   | 物品名 / tooltip         | 掉落光          | 来源         |
| --- | ---- | --------------------- | ------------ | ---------- |
| 低阶  | 白色   | `§f`                  | 无            | 出厂、铜、未附魔铁  |
| 中阶  | 金色   | `§6`                  | 淡金粒子         | 铁、金        |
| 高阶  | 蓝色   | `§9`                  | 蓝色附魔光        | 附魔金、下界合金   |
| 彩虹  | 彩虹流光 | 名称逐字循环 `§c§6§e§a§b§d` | 彩虹附魔光 + 周期粒子 | 下界合金 + 高附魔点数 |


抽词条时：先抽品阶，再从「通用池 + 该武器专有池」里均匀抽 1 条。专有词条只出现在对应武器上，不进其他武器。

一把武器同时只有 1 条锻纹。再铸覆盖。

**开槽**

锻造台：

- 模板槽：对应模具
- 基底：武器（空白或已锻纹均可）
- 材料槽：1 铜锭（钻孔耗材，固定）

产出：带空槽的同一把武器。耐久上限此时不降。空槽在 tooltip 显示「镶镶嵌槽 □」。

**镶嵌**

再次上锻造台（不再耗模具）：

- 基底：有空槽的武器
- 材料：1× **镶嵌物**（金属锭或宝石）
- 镶嵌物可先在附魔台上附魔

产出：该槽填入镶嵌物。槽位写「镶嵌 · 金 / 钻石 · 效果」。

可镶嵌物与基础效果（铁阶绝对值，不受锻纹倍率影响）：


| 镶嵌物    | 基础效果                      | 耐久上限 | 附魔条目 + |
| ----- | ------------------------- | ---- | ------ |
| 铜锭    | 攻速 +0.05                  | −15% | +0     |
| 铁锭    | 伤害 +1                     | −10% | +0     |
| 金锭    | 附魔能力 +8                   | −20% | +1     |
| 下界合金锭 | 伤害 +1，耐久上限不降              | 0%   | +1     |
| 煤炭    | 对着火目标 +2                  | −8%  | +0     |
| 红石    | 攻速 +0.10                  | −8%  | +0     |
| 青金石   | 获得经验 +20%                 | −8%  | +1     |
| 紫水晶碎片 | 暴击伤害 +0.25（原版 1.5 → 1.75） | −8%  | +0     |
| 绿宝石   | 对村民相关伤害不增；与村民交易时该武器不掉声望   | −8%  | +1     |
| 钻石    | 伤害 +1，耐久损耗 −10%           | −5%  | +1     |
| 下界石英  | 对下界生物 +2                  | −8%  | +0     |


两槽时效果叠加。耐久惩罚 **加算后乘在最大耐久上**，下界合金槽贡献 0。

例：铁剑耐久 250，嵌铁（−10%）+ 钻石（−5%）→ 最大耐久 250 × 0.85 = 212。  
嵌下界合金 + 钻石 → 只算钻石 −5%。

**附魔条目**

原版一件物品可同时存在的不同附魔种类，受冲突规则限制（锋利 / 亡灵杀手互斥等）。

「附魔条目 +N」= 这件武器允许 **额外再保留 N 条本来会放不下或互相冲突被挤掉的附魔**。  
实现上：提高自定义上限，不打破「同一附魔只一条」。冲突组（锋利 vs 亡灵杀手）仍互斥。

镶嵌物本身带的附魔，在镶入时 **尝试写到武器上**：

- 武器没有该附魔：直接获得，等级不变
- 武器已有且更低：升到镶嵌物的等级
- 武器已有且更高：不变
- 放不下且条目 + 已用完：该附魔消失，不返还

镶嵌物消耗。想换镶嵌物：砂轮「卸下镶嵌」→ 空槽 + 无附魔的镶嵌物胚（附魔不退）。锻纹不受卸下镶嵌影响。

**顺序建议（非强制）**

1. 合成出厂（带低阶锻纹）
2. 砂轮洗成空白（可选）
3. 高炉用附魔金属重铸锻纹
4. 锻造台钻孔
5. 附魔台给武器 / 镶嵌物附魔
6. 镶嵌，用条目 + 塞进更多附魔
7. 锻造台把技巧模板当模板装上。这一步与钻孔无关，随时可做

可打乱，但先钻孔再附魔更不容易浪费条目。技巧模板不占附魔条目。

**和砂轮、铁砧**


| 操作        | 锻纹     | 槽    | 镶嵌物        | 附魔与技巧模板          |
| --------- | ------ | ---- | --------- | -------------- |
| 砂轮        | 清除，变空白 | 保留   | 卸下，镶嵌物变无魔胚 | 一并清除，技巧模板不返还     |
| 铁砧合并两把同武器 | 保留左边   | 槽数取高 | 左满则丢右     | 附魔按原版合并；技巧模板留左边  |
| 铁砧修耐久     | 不动     | 不动   | 不动        | 不动             |
| 锻造台装技巧模板    | 不动     | 不动   | 不动        | 消耗一枚技巧模板，装上或替换；其它附魔保留 |


砂轮若一次清太多：配置项可改成「第一次只卸下镶嵌，第二次去锻纹，第三次去附魔」。默认一次全清，避免操作谜题。

## 3. 装备类

肩甲、锁链内衬，以及肩带、腰带、背带这三件装备本身，画在原版物品栏右侧那一列，和 1.0 的两套装扮放在一起。不使用 Accessories，不占盔甲四槽。五件可以同时穿。没有套装加成。

### 3.1 肩甲

不提供防护加值，也不代替盾。只有在真正举盾时：

- 格挡角 +10°
- 被破盾的禁用时间 −0.5 秒，最低仍为 1 秒

### 3.2 锁链内衬

新物品。原版锁链甲仍是胸甲，不能改成内衬。

- 可与任何胸甲同时穿。
- 不提供护甲值，也不提供韧性。因此它不把目标变成「有甲」，穿刺和钝击的类型修正不看它。
- 在盾的减免之后，近战伤害再 −1。弹射物、爆炸、魔法不减。本次伤害小于 2 时不减，避免把 1 点伤害抹成 0。
- 耐久 120。损耗与胸甲分开计。

合成：4 锁链 + 1 皮革，工作台，锁链放四角。盔甲匠专家也卖，基础价 12 绿宝石。

**武器肩带**

左腋、右腋各是一个独立的物品栏格子，模型画在对应的腋下。两格互不影响。每格可以放一把小型武器、一面小圆盾，或一只灯笼。

**武器腰带**

左腰、右腰各是一个独立的物品栏格子。每格可以放一件中型武器、一面中盾，或一只灯笼。箭袋和药水袋不挂在这里。

**武器背带**

背后是一个独立的物品栏格子，模型在背上。这一格可以放一件重型武器、一面大型盾牌，或一只灯笼。

**箭袋和药水袋**

这两件要在普通背包或快捷栏里才生效。放进肩带、腰带、背带的延伸格不算。同一种袋子有多只时，也只打开一套 4 格。

背包或快捷栏里有箭袋时，背包界面多出 4 个箭矢格，从左到右接受箭、药箭、光灵箭、烟花火箭，每格最多 64。拉弓只从这里拿箭、药箭、光灵箭。上弩时这四种都算，按格子顺序用最先符合的一格。这 4 格空了，或没有能用的那一种，再搜普通背包。

背包或快捷栏里有药水袋时，同样多出 4 个药水格，只接受药水、喷溅型药水、滞留型药水。不自动喝，从这 4 格取出再使用。

最后一只箭袋或药水袋离开背包和快捷栏时，对应的专门格关闭。里面的东西先回到普通物品栏，放不下的掉在脚下。


| 物品   | 合成          | 交易                            |
| ---- | ----------- | ----------------------------- |
| 武器腰带 | 5 皮革 + 1 铁锭 | 皮匠工匠，8 绿宝石                    |
| 武器肩带 | 4 皮革 + 2 铁锭 | 武器匠专家，10 绿宝石                  |
| 武器背带 | 无合成         | 武器匠大师，16 绿宝石 + 1 钻石；远古城市箱 10% |
| 箭袋   | 6 皮革 + 2 线  | 制箭师工匠，6 绿宝石                   |
| 药水袋  | 6 皮革 + 1 玻璃瓶 | 牧师工匠，6 绿宝石                    |


背带能把重武器留在背后，所以不给廉价合成。箭袋和药水袋只负责在背包里打开专门格。
